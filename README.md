# Nuguseo Mirror Cast TV 배포

Google TV용 Nuguseo Mirror Cast TV APK와 설치용 다운로드 페이지를 공개 배포하는 저장소다.

## 역할

- 버전별 TV APK 보관 및 다운로드 제공
- Downloader 앱에서 접근할 수 있는 간단한 설치 페이지 제공
- `mirror-sites.json`과 `site-manager.js`를 이용한 미러 사이트 관리

현재 `index.html`에 표시된 배포본은 `v0.2.5`다. 새 버전을 올릴 때 APK 파일, 다운로드 링크, 화면의 버전 표기를 함께 갱신하고 실제 TV 설치를 확인한다.

이 저장소는 공개 저장소다. 서명키, API 키, 고객정보는 절대 올리지 않는다.
